# Himgatha Trails – Trekking Website

A modern, premium trekking website built using React + Vite + Tailwind.

## 🚀 Features
- Dynamic trek pages
- WhatsApp booking integration
- Smooth animations (Framer Motion)
- Responsive design
- Premium UI/UX layout

## 💼 Project Type
Freelance-style / Client-based project (concept build)

## 🛠 Tech Stack
- React (Vite)
- Tailwind CSS
- Framer Motion
- React Router
